# JS 도매 주문 웹앱 (v0.1)

거래처 전용 도매 주문 웹앱이에요. 제품 설명, 수량별 단가, 견적·주문 요청 기능이 있어요.
처음부터 **나중에 안드로이드·아이폰 앱으로 포장할 수 있는 구조**로 만들었어요.

## 들어 있는 기능
- 제품 목록, 검색, 카테고리
- 제품 상세: 수량별 단가표, 수량을 바꾸면 총액이 자동 계산되고, 다음 할인 구간까지 남은 수량을 안내해요
- 최소 주문 수량(MOQ), 박스 단위, 개당 환산가
- 로그인한 거래처에게만 도매가 표시
- 견적함(장바구니) → 견적·주문 요청 → 요청번호 발급, 요청 내용 복사
- 요청 내역과 "같은 구성으로 다시 담기"
- 한국어 / 베트남어 전환
- 관리자 화면: 제품·가격 구간 추가, 수정, 삭제 → `products.json` 내보내기
- 홈 화면 설치(PWA), 오프라인 화면

데모 거래처 코드는 `DEMO`, 관리자 PIN은 `0000`이에요.

## 파일 구조
```
index.html              시작 화면
css/app.css             디자인
js/i18n.js              한국어·베트남어 문구
js/data.js              데이터 계층 (서버를 붙일 때 이 파일만 바꿔요)
js/app.js               화면과 동작
data/products.json      제품·가격 데이터
manifest.webmanifest    앱 이름·아이콘 (홈 화면 설치용)
sw.js                   오프라인 지원
icons/                  앱 아이콘
```

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소를 만들어요. (예: `js-order`)
2. **Add file → Upload files**에서 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓고 Commit해요.
3. **Settings → Pages → Branch: main / (root) → Save**를 눌러요.
4. 1–2분 뒤 `https://<아이디>.github.io/js-order/` 주소로 열려요.

## 제품·가격 바꾸는 방법
- **쉬운 방법**: 앱에서 내 정보 → 관리자 → 수정 → **products.json 내보내기**를 눌러요. 받은 파일을 GitHub의 `data/products.json`에 덮어 올리면 모든 거래처 화면에 반영돼요.
- **직접 수정**: `data/products.json`을 편집해도 돼요. `tiers`는 `[{ "min": 박스수, "price": 박스당가격 }]` 형식이에요.
- 사진을 쓰려면 `images/` 폴더에 올리고 `"image": "images/파일명.jpg"`로 적어요.
- 파일을 고친 뒤에는 `sw.js`의 `js-v1`을 `js-v2`처럼 올려 주세요. 그래야 설치된 앱도 새로 받아요.

## ⚠️ 실제 운영 전에 꼭 필요한 것 (지금은 시제품)
- **가격 보안**: 지금은 `products.json`이 공개 파일이라서 주소를 아는 사람은 가격을 볼 수 있어요. 로그인 코드 `DEMO`도 데모용이에요. 실제 운영에서는 서버(Supabase 또는 Firebase 추천)에 가격을 두고, 로그인한 거래처에게만 내려주도록 바꿔야 해요.
- **요청 접수**: 지금은 요청이 **보낸 사람의 기기에만** 저장돼요. 서버를 붙이면 사장님이 관리자 화면에서 모든 요청을 보고, 카카오톡이나 이메일 알림도 받을 수 있어요.
- 두 작업 모두 `js/data.js`의 함수만 교체하면 되고, 화면 코드는 그대로 써요.

## 나중에 앱으로 바꾸기
- **안드로이드(구글 플레이)**: 공개된 주소를 https://www.pwabuilder.com 에 넣으면 플레이스토어용 패키지를 만들어 줘요. (구글 개발자 등록비 $25, 1회)
- **아이폰(앱스토어)**: Capacitor로 포장해요.
  ```
  npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android
  npx cap init JS com.jstrading.order --web-dir=www
  # 이 폴더의 파일을 www/ 에 복사한 뒤
  npx cap add ios && npx cap open ios
  ```
  애플 심사는 "웹사이트를 그냥 감싼 앱"을 거절할 수 있어요. 푸시 알림(주문 상태 변경 알림 등)을 추가한 뒤 심사를 신청하는 걸 추천해요. (애플 개발자 등록비 연 $99)
- 이 웹앱은 상대 경로와 `#/` 주소 방식을 써서 앱 안에서도 그대로 동작해요.
